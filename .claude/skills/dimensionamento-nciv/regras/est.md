# Estrutural (EST)

**Fonte:** Julia Lee ("Julee", PO do EST), bench + planilha oficial.

## Variáveis principais

Base: **sobrado de 200m² = 5 semanas.** Some os ajustes a partir dela:

| Variável | Faixa | Ajuste |
|---|---|---|
| Tamanho da casa | <50m² | -2 semanas |
| | <150m² | -1 semana |
| | >300m² | +1 semana |
| | >400m² | +2 semanas |
| | >500m² | +3 semanas |
| Complexidade do terreno | Plano | sem alteração |
| | Inclinado | +1 semana |
| | Tão inclinado a criar novo andar | +2 semanas |
| Andares | Sobrado | sem alteração |
| | Mais andares (diferentes entre si) | +1 semana |
| | Prédio (andares parecidos) | análise diferente (ex: Guarulhos, 7 andares, ~9 semanas) |
| Complexidade | Solução estrutural muito complexa | +1 semana |
| | Algo que ainda não fizeram | +1 semana |

**Piscina:** +1 semana.

**Teto prático:** dificilmente passa de 8-9 semanas. Se o ajuste ultrapassar, pare e sinalize.

## Critérios não-óbvios

São geométricos e só aparecem olhando a planta. Nenhum sai de metragem, endereço ou valor de contrato: **sem a planta, o EST fica incompleto por definição.**

- Janelas muito grandes
- Paredes que não se alinham entre pavimentos
- Pé-direito muito alto
- Paredes inclinadas
- Encanamento no subsolo (nunca vem informado nos cards; importante mapear)
- Cômodos maiores que o padrão (~6x6m), ex: "garagem que ocupa o terreno inteiro"
- **Planta arquitetônica terceirizada de baixa qualidade** (paredes desalinhadas, medidas inconsistentes, subsolo menor que o terreno): **não avaliável pela skill**, sempre checagem manual

## Restrições de escopo

- **Só concreto armado** como solução estrutural própria.
- **Steel frame, tijolo ecológico e alvenaria estrutural** não são feitos internamente, mas podem ser **terceirizados com o engenheiro parceiro Clau**. Esses sistemas não estão mapeados aqui: não use as faixas de concreto armado; quem precisar dimensionar pergunta ao Clau.
- **Muro de arrimo:** nunca foi feito internamente. Fora do escopo padrão, não é ajuste de prazo.
- **Elevador: inviável total.** Saiu de "complexidade +1 semana" na planilha (um texto antigo dela ainda não foi corrigido; desconsidere qualquer menção a elevador como +1). Não é caso de fronteira: vai direto para inviabilidade.
- **Inviáveis:** pavimentação (nunca aceitam, nem de prefeitura/condomínio), edifícios muito altos, estruturas não convencionais, contenção de alta complexidade, infraestrutura urbana.
